## 修复：桌面端（Electron）界面四周仍有「间隙」——根因是 scoped CSS 的 `:global()` 被编译丢弃

### 现象
用户反馈 Electron 打包后运行，界面仍为网页版「居中悬浮卡片」：四周各 20px 空白 + 14px 圆角 + 边框阴影，
与期望的「铺满整个窗口」不符。这是同一问题第二次被反馈。

### 根因（真正的坑）
`src/views/ChatLayout.vue` 的 `<style scoped>` 里用了：

```css
:global(html.is-desktop) .shell { padding: 0; background: var(--panel); }
:global(html.is-desktop) .window { width: 100%; height: 100%; ... }
```

编译后**后代选择器 `.shell` / `.window` 被整段丢掉**，产物退化成：

```css
html.is-desktop{padding:0;background:var(--panel)}
html.is-desktop{width:100%;height:100%;border-radius:0;border:none;box-shadow:none}
```

规则落到了 `<html>` 上，`.shell` / `.window` 从未被命中 → 看起来「改了但完全没生效」。
结论：**Vue SFC scoped 样式里不要用 `:global(X) .descendant` 这种组合写法**，
后代选择器会丢。改用「模板上直接绑类 + 普通 scoped 选择器」即可。

### 修法
1. 新增 `src/utils/desktop.ts`：`IS_DESKTOP` 作为桌面端判定的唯一入口 ——
   优先 `window.lufengDesktop?.isDesktop`（preload 经 contextBridge 注入），
   兜底 `navigator.userAgent.includes('Electron')`（preload 失效也能生效）。
2. `src/main.ts`：改用 `IS_DESKTOP`，给 `<html>` 加 `is-desktop`。
3. `src/styles/global.css`：新增 `html.is-desktop, html.is-desktop body { background: var(--panel); overflow: hidden }`。
4. `src/views/ChatLayout.vue`：
   - 模板 `<div class="shell" :class="{ 'is-desktop': isDesktop }">`；
   - 样式改为普通 scoped 选择器 `.shell.is-desktop{...}` / `.shell.is-desktop .window{...}`。

编译后产物（已验证）：
```css
.shell.is-desktop[data-v-e9455155]{padding:0;background:var(--panel)}
.shell.is-desktop .window[data-v-e9455155]{width:100%;height:100%;border-radius:0;border:none;box-shadow:none}
```

## 功能：Electron 打开 DevTools + 聊天框粘贴上传图片/视频

用户问「运行 electron 怎么打开控制台」且「复制的图片/视频不能直接粘贴到输入中」。

### DevTools 打开（electron/main.cjs）
- 开发态（`!app.isPackaged`，即 `electron .` 直接跑）`mainWindow.webContents.openDevTools()` 自动开。
- 生产态打包 exe：在 `webContents` 的 `before-input-event` 里监听 `F12` 或 `Ctrl+Shift+I` → `toggleDevTools()`。
  因菜单栏已 `Menu.setApplicationMenu(null)`，右键 Inspect 不可用，快捷键是主入口。

### 粘贴上传（src/components/chat/MessageComposer.vue）
- textarea 加 `@paste="onPaste"`：从 `clipboardData.files`（文件管理器复制的文件对象）或 `clipboardData.items`（截图工具复制的图片 blob）挑出图片/视频，
  直接调已有的 `sendMedia` 走上传+发送；纯文本粘贴不拦截（`files.length===0` 时直接 return）。
- 新增 `mediaKindOf(file)`：MIME 优先（`image/*`/`video/*`），扩展名兜底判定图片/视频，避免复制文件时 type 为空的误判。
- placeholder 提示「可粘贴图片/视频直接发送」。
